# System Scope | 系统边界

## 1. Research Scope | 研究范围

本项目聚焦于**受监管的第三方检验检测实验室**在**现实约束条件**下的运营与治理。核心关注点包括：
- **数据可信** (Data Integrity & Trust)
- **生命周期控制** (Lifecycle Control)
- **组织失效与反模式** (Organizational Degeneration & Anti-patterns)
- **低成本数字化治理** (Low-cost Digital Governance)

## 2. Core Objects | 核心对象

- 中小型第三方检测实验室
- 大型检测机构的质量与运营单元
- 强监管环境下的合规与质量职能

## 3. Exclusions | 不研究什么

- 通用企业ERP或财务系统
- 高级算法或AI模型
- 纯硬件工程或仪器研发
- 无监管要求的非标实验室

## 4. Purpose | 目的

确保所有主题都围绕“实验室数字治理”这一核心，防止范围无限扩张。
